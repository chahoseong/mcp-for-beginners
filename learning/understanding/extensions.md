## 후속 확인 목표

- working과 실제 결과의 구분·상태 추적 흐름은 테스트 사례에서 확인했다. 이후 구현 수업에서 작업 식별자와 조회 메서드를 연결한다.
- Task 상태·완료와 최종 도구 결과의 의미를 구분한다. 상세 입력 요청·취소·저장·SDK 구현은 이 수업에서 요구하지 않는다.
