| 개념 | 관련 모듈 | 상태 | 확인 근거 | 마지막 확인일 | 후속 과제 |
| --- | --- | --- | --- | --- | --- |
| Tools와 Resources | 00 | 적용 확인 | 같은 파일도 제공 방식에 따라 Tool 또는 Resource가 될 수 있음을 논의했다. 학습 도우미에서 실행은 Tool, 코드와 학습 노트는 Resources로 설계했다. | 2026-10-01 | 구현 시 함수 이름이나 데이터 종류가 아니라 MCP 제공 방식으로 구분한다. |

| 모델의 예측과 실행 증거 | 00 | 부분 이해 | 모델의 예측과 도구의 실제 실행 결과를 구분했다. 이후 모델의 판단에도 분석 근거가 있을 수 있고, 종료 코드 0이 정답·무결함을 보장하지 않는다고 보충했으나 재확인은 하지 않았다. | 2026-10-01 | 종료 코드 0과 기능의 정확성을 구분하는 사례로 복습한다. |
| Python 학습 도우미 설계 | 00 | 적용 확인 | 코드 실행 Tool과 코드·학습 노트 Resources를 필요한 구성으로 제안했다. | 2026-10-01 | 도구 호출 및 데이터 전달 흐름을 실제 구현으로 연결한다. |

## 다음 확인 질문

- 덧셈 함수가 뺄셈을 수행해도 종료 코드 0으로 끝날 수 있는가? 이 결과로 무엇까지 확인할 수 있는가?
- 코드 설명용 Prompt 템플릿이 코드를 실제로 실행하거나 답변을 생성하는가?
- 실행 성공의 의미를 보충한 이후 재확인하지 않았으며, Prompts는 설명 이후 직접 답변으로 확인한 적이 없다.
