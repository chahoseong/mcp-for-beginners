## 다음 확인 질문

- 2026-10-06 Sampling 단원 검토: 현행 명세의 deprecated 상태·신규 직접 LLM API 대안과 원문의 레거시 예제 차이를 보충했다. 과거 Sampling 이해 확인은 유지한다. 이번 검토만으로 실제 구현이나 새 독립 이해 근거를 추가하지 않는다.
- 현재 설명한 Elicitation·Roots·Sampling·Logging의 확인 질문은 해결했다.
- 프로토콜 버전별 메시지 절차와 구현 능력은 아직 평가하지 않았다.

## 확인 방식의 한계 — 2026-10-01 검토

- 각 항목은 설명 직후의 역할 선택·분류·예 또는 아니요 답변으로 확인했다. 기존 상태를 유지하되 독립적인 절차 설명이나 새 사례 적용까지 확인한 것은 아니다.
- Elicitation 흐름 등 현재 수업의 핵심은 다른 사례로 다시 확인한다. 폐기 예정 기능의 세부 구현을 불필요하게 재시험하지 않는다.
