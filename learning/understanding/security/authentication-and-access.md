## 확인 방식의 한계 — 2026-10-01 검토

- 인증·인가 분류, 사용자 동의, 입력 검증은 직전 설명과 같은 사례 또는 유도 질문으로 확인했다. 입력 검증 답변에는 이유가 있었지만 독립적인 새 사례 적용을 평가한 것은 아니다.
- 기존 이해 확인을 보존하되 독립 이해의 근거가 제한적임을 함께 해석한다. 보안 개요를 다른 사례에서 설명·진단하게 하여 필요한 구분을 재확인한다.


## 이후 확인

- 감사 기록의 구체적 검사 절차는 아직 가르치지 않아 평가를 중단했다. 실제 구현을 배울 때 관련 범위만 확인한다.
- 도구 목록 표시와 서버 접근 통제의 구분은 아직 별도로 확인하지 않았다.
