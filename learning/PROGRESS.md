## 에이전트의 읽기·갱신 규칙

- 학습 시작 전에 이 문서와 현재 수업 기록을 읽고, 다음 설명에 필요한 이해 기록만 추가로 읽는다. 전체 디렉토리를 매번 읽지 않는다.
- 필요한 수업·개념 기록이 없으면 해당 디렉토리에 새로 만들고 이 문서와 관련 기록에 링크를 추가한다. 기존 개념 기록이 있으면 재사용하며, 학습자의 답변 근거가 없는 이해 상태는 '미확인'으로 둔다.
- 이해 상태의 기준은 학습자의 답변이다. 설명만 한 내용은 이해 확인으로 표시하지 않는다.
- 이미 확인된 기초 설명은 반복하지 않고, 남은 혼동을 확인하거나 다음 수준의 적용 질문을 선택한다.
- 복습 질문은 학습 흐름에 맞게 하나씩 제시한다.
- 이해 확인 질문을 한 뒤에는 학습자의 답변을 기다리고, 답변을 확인하기 전에 다음 주제로 진행하지 않는다.
- 개념의 최신 상태·근거·마지막 확인일·후속 과제는 understanding/의 해당 파일 한곳에서 갱신한다. 여러 문서에서 같은 개념을 학습하면 기존 기록을 재사용한다.
- 이해 기록은 관련 개념을 묶어서 관리하며, 새 주제를 학습할 때 필요한 파일만 추가한다.
- 수업별 범위와 날짜별 이력은 lessons/에 기록한다. 당시 결과는 보존하고, 최신 이해 상태는 링크로 참조한다.
- 복습으로 해결된 질문은 최신 이해 기록에서 제거하고, 확인 근거와 상태를 갱신한다. 변경 근거는 해당 수업의 이력에 추가한다.
- 같은 날짜의 세션은 제목으로 구분한다. 과거 기록의 오류를 수정할 때는 수정 이유를 남긴다.
- 학습 종료 시 이 문서의 현재 위치·다음 행동·상세 기록 링크와 해당 수업의 남은 범위를 갱신한다.
- 이해 수준과 실제 구현·실행 경험을 구분하고, 문서의 주장과 보충 설명도 구분한다.

## 학습 기록 재구성 규칙

- 모듈 완료 또는 퀴즈·테스트·실습 평가 종료 시 기록 구조를 점검한다. 점검할 때마다 재구성할 필요는 없다.
- 같은 개념의 중복 기록이나 상태 불일치, 필요한 근거를 찾기 어려운 파일 길이, 구현 학습에 따른 세분화 필요, 해결된 복습 항목이나 오래된 안내가 발견되면 재구성을 검토한다.
- 에이전트는 필요에 따라 `learning/` 안의 파일을 분리·통합·이동하고 구성을 자율적으로 정리할 수 있다. 정리한 뒤 변경 내용과 이유를 학습자에게 알린다.
- 재구성 대상은 `learning/`의 학습 기록이다. 원본 교육 문서 수정은 별도의 작업으로 다룬다.
- 학습자의 답변 근거와 날짜별 학습·복습 이력은 보존한다. 이력을 다른 파일로 옮길 때도 기존 기록과 출처를 유지한다.
- 개념별 최신 이해 상태는 한곳에서 유지한다. 상태가 서로 다르면 답변 근거와 날짜를 확인하며, 근거 없이 높은 상태를 선택하지 않는다. 판단할 수 없는 항목은 재확인 질문으로 남긴다.
- 파일 이동·통합 자체를 이유로 이해 상태를 바꾸지 않는다. 상태 변경은 학습자의 답변이나 평가 결과에 근거하며, 변경 근거는 수업 이력에 기록한다.
- 모듈 완료와 모든 개념의 이해 확인을 구분한다. 미확인 또는 보완할 항목은 다음 학습에도 이어간다.
- 재구성 시 이 문서의 상세 기록 링크와 필요한 읽기 안내를 함께 갱신한다. AGENTS.md의 경로·규칙에도 영향이 있으면 함께 수정한다.
- 연결된 파일과 링크가 유효하고 답변 근거·이력이 누락되지 않았는지 확인한다.
- 재구성 날짜, 이유, 주요 이동·분리·통합 내역을 해당 수업 기록의 이력에 짧게 남긴다. 여러 수업에 걸친 변경도 관련 수업 기록에서 추적할 수 있게 한다.
