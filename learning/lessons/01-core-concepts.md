## 재개 시 확인

- Rate Limiting은 재설명 후 이해 확인이다. 고정된 사용자별 배분을 제안했으며 전체 한도·동적 배분·구현까지 확인한 것은 아니다. 감사 기록의 상세 절차 질문은 현재 반복하지 않는다.
- 설명 직후 예·아니요 또는 단순 선택으로 확인한 항목은 독립적 이해의 증거가 제한적이다. 관련 개념 기록의 한계를 읽고 핵심 개념을 자연스럽게 재확인한다.
- 설계 결과: execute-script, 필수 filepath: str, 실행 결과 또는 트레이스 반환, 모델이 실행 근거로 코드 리뷰. 원문 개요 연습을 충족했으며 출력 필드 세분화는 현재 강제하지 않는다.
- Module 00에서 남은 종료 코드 0과 기능 정확성의 구분은 도구 설계·실습과 연결해 확인한다.

## 원문을 가르칠 때 주의할 점

- 원문에 이전 버전의 초기화·세션 설명과 2026-07-28 요청별 메타데이터 안내가 혼재한다. 버전 차이를 구분한다.
- Roots·Sampling·Logging은 원문에서 폐기 예정 기능으로 소개한다. 현재 기능과 호환 설명을 구분한다.
- 원문의 Python 실행·클래스 메서드 등록 예시는 현재 FastMCP 문서와 차이가 있다. 보충 설명을 실행 검증한 것으로 표현하지 않는다.
- 날씨 반환값은 고정 예시 데이터이다. 최대 7일·분당 10회는 선생님의 보충 조건이며 원문 코드의 제약이 아니다.
- 도구별 동의 문구를 모든 호출의 새 확인창 요구로 일반화하지 않는다.
