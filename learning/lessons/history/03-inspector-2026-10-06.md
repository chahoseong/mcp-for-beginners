- 수업 계획 작성(2026-10-06): 그림으로 Inspector 역할/호출 흐름→기존10 Python 서버의 정상 호출과 id 추적→오류 응답/서버 코드 근거 비교→guide Resource·explain Prompt의 UI 확인 순서이다. 원문 깊이의 디버깅에 집중하며 새 서버/가상환경은 만들지 않는다. 요청 전달 전에 UI/CLI가 막으면 서버 오류와 구분하고 필요 시 기존 Client로 요청한다. 알림 관찰은 기존06을 필요할 때 재사용한다. 그림 뒤 JSON과 실제 화면을 연결하고 새로운 로그 사례를 설명하는 집중 확인 후 다음 단계로 진행한다. 승인·실행은 아직 없다.
- 시작(2026-10-06): 학습자가 계획을 승인했다. Inspector 화면/내부 MCP Client/서버의 흐름과 프로토콜 메시지·서버 내부 로그를 구분해 설명하고 기존10 서버를 Inspector2.9.0에 연결하도록 안내한다. 연결·목록 제출과 이해 평가 결과는 아직 없다.
- 정상 호출 확인(2026-10-06): 연결·add/multiply 목록과 multiply(6,4)의 응답 id5·결과24·isError:false를 제출했다. 요청을 찾지 못해 제출한 캡처에서 Protocol 카드의 TOOLS/CALL·Parameters(name/arguments/_meta.progressToken5)·Response를 확인했다. UI는 요청 전체 JSON이 아닌 params를 보여주므로 요청 id 직접 관찰과 응답 규칙에 따른 추론을 구분하고 progressToken을 요청 id로 읽지 않도록 보충한다. 하단 resources/templates/list ERROR는 원인 미확인이다. 독립 해석 평가는 아직 없다.
- 교정 필요: Inspector v2의 Node 요구조건·화면/CLI를 공식 문서로 확인하고 Streamable HTTP를 사용한다. 필수 인자 누락을 항상-32602로 일반화하지 않으며 isError도 확인한다. 알림은 응답 쌍이 없고 Inspector만으로 내부 실행 단계를 모두 알 수 없다. McpError 문자열 생성·광범위 예외 노출·VS Code 실행 예시는 그대로 복사하지 않는다. 원문은 수정하지 않았다.

- 실패 비교 실행(2026-10-06): Inspector CLI에서 add(b=3)의 검증 오류/isError:true와 별도 tool_is_error 안내, guide://missing의 code:"error"/Unknown resource 안내를 제출했다. 뒤의 문자열 code는 CLI 표시이며 숫자 JSON-RPC 코드가 아니다. 서버 코드의 MCPError(INVALID_PARAMS) 분기와 비교해-32602를 설명하되 실제 wire 응답을 직접 제출한 것으로 기록하지 않는다. 서버 계산/Resource handler 전의 반환·거부를 설명했고 독립 진단 확인은 답변 대기 중이다.
- 진단 확인(2026-10-06): 새 가상 save_note 실패 결과에서 서버 저장 공간을 우선 조사하고 디스크 공간 부족 메시지가 근거라고 답했다. 조사 대상·근거 선택을 확인하며 실제 장애 검증/복구와는 구분한다. 최신 상태는 Python Client 기록을 따른다. 이후 기존 Resource·Prompt의 Inspector UI 확인을 안내한다.

## 마무리 근거

- 2026-10-06 Inspector UI에서 guide://calculator의 params와 id6/contents(URI·text/plain·안내문), explain_calculation(expression=6 * 4)의 params와 id9/messages(role:user·계산식 포함)를 제출했다. 안내된 실습이며 모델 생성 답변은 없다.
- 마지막 가상 로그에서 학습자가 조사 목적을 질문해 잘못된 결과의 원인 찾기·성공 여부와 정확성 차이를 보충했다. 이후 요청 A의 응답 Y를 점검해야 하며 기대32 대신31이라고 설명했다. 목적 보충 뒤의 결과 비교이며 서버 코드/로그 선택·id 연결 이유의 명시적 답변은 없다.
- 정상/실패 호출과 Resource/Prompt UI 확인의 보충 수업을 완료했다. HTTP 인증의 Inspector 실제 연결, 새로운 notification 실행·로그 내보내기·VS Code 시작 설정은 선택으로 남겼다. Inspector 중지는 안내하며 실행 확인은 없다.
- 누적 계획/진단 경위를 이 파일로 보존하고 모듈은 재개 요약으로 줄였다. 기록 이동으로 기존 평가를 바꾸지 않았다.
