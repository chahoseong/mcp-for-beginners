- 환경 확인: 학습자가 03-llm-client/.venv/Scripts/python.exe, mcp 2.2.0, openai 3.24.0, Imports OK를 제출했다. 안내에 따른 환경·import 확인이며 모델 연결은 아직 하지 않았다. 다음은 solution/python/server.py migration과 Tool 목록 조회이다.
- MCP 연결 확인: migration·작은 Client 안내 후 Connected와 add의 description·input_schema 출력을 제출했다. properties의 a/b는 integer이고 required는 두 인자를 포함한다. 안내에 따른 연결·명세 조회 경험을 확인했으며 schema 해석·LLM 연결은 아직 평가하지 않았다. 다음은 JSON Schema와 모델용 Tool 정의 변환이다.
- schema 확인: required를 누락하면 모델이 필수 값을 생략할 수 있고 서버에서는 필수 입력 누락으로 실패한다고 설명했다. 설명 직후의 진단으로 이해 확인했다. 다음은 convert_to_llm_tool을 연결해 전체 input_schema가 parameters에 보존되는지 출력 확인이다.
- 변환 출력 확인: 학습자가 add의 모델용 Tool 정의를 제출했으며 parameters에 integer 필드와 required가 보존되었다. 안내에 따른 변환 실습을 확인했다.
- NIM 모델 선택: 학습자가 DeepSeek V4.1 Flash와 hosted API 사용 예시를 제공했다. endpoint는 https://integrate.api.nvidia.com/v1, 모델 ID는 deepseek-ai/deepseek-v4.1-flash, 키는 NVIDIA_API_KEY에서 읽는다. 예시는 이미지 입력·일반 Chat Completion이며 tools 전달은 없다. NVIDIA 공식 모델 문서에서 Tool Calling 지원을 확인했다. 다음은 짧은 텍스트 요청으로 모델 연결 확인이다.
- NIM 연결 확인: 학습자가 uv run --env-file 방식 실행 후 finish_reason=stop과 한국어 인사 응답을 제출했다. 안내에 따른 모델 연결·텍스트 응답 경험을 확인했다. 다음은 llm_tools 전달과 tool_calls의 이름·인자 출력이며 MCP Tool 실행은 아직 하지 않았다.
- LLM 호출 요청 확인: llm_tools·system 안내·tool_choice=auto 전달 실습에서 학습자가 finish_reason=tool_calls, content=None, 호출 ID, add와 a=20/b=2를 제출했다. 안내한 요청의 모델 선택·JSON 인자 변환 출력을 확인했다. 아직 실제 MCP 실행 결과는 아니며 다음은 call_tool·실패 결과·예외 처리 연결이다.
- MCP 실행 확인: 학습자가 finish_reason=tool_calls, Tool is_error=False, Tool result={'result':22}를 제출했다. 안내한 add 요청의 실제 실행 결과를 확인했다. 다음은 assistant 호출 메시지·tool_call_id가 있는 tool 결과 메시지를 대화에 추가해 최종 모델 답변을 얻는 단계이다. 오류 분기는 이 출력으로 평가하지 않는다.
- 최종 답변 확인: 학습자가 첫 응답 tool_calls → MCP is_error=False·result=22 → 두 번째 응답 stop·한국어 최종 답변 22를 제출했다. 안내에 따른 두 번의 모델 호출·실행 결과 재전달 흐름의 정상 동작을 확인했다. 호출 ID 연결의 독립 이해·실패 결과 전달·추가 호출 반복은 아직 평가하지 않았다. 다음은 두 호출의 결과 연결 사례 확인 후 추가 계산 Tool 응용이다.
- 호출 ID 확인: 두 재고 조회의 결과를 8·0으로 각각 연결하고 모델에서 받은 ID 사용을 명시했다. 실제 call_A/B 보존을 보충한 뒤 ID만 바뀌면 재고를 0·8로 해석한다고 진단했다. 집중 후속 확인으로 ID·결과 연결은 이해 확인했으며 복수 호출 구현은 미평가이다. 다음은 학습자가 계산 Tool을 하나 추가해 기존 add와 새 Tool의 자연어 선택·실행·최종 답변을 비교하는 응용 과제이다.
- 응용 과제 진행: 학습자가 뺄셈 결과 121과 최종 답변 "141에서 20을 빼면 121"을 제출했다. 실제 server.py에서 subtract(a:int,b:int)->int, docstring, @mcp.tool, return a-b를 확인했다. Client에는 호출 이름·인자 출력이 없어 제출 결과만으로 선택값을 직접 확인하지 않았다. 새 Tool이 함께 등록된 상태의 add 실행 결과도 아직 제출되지 않았다. 다음은 두 요청의 Tool name·Arguments·MCP 결과·최종 답변 출력 확인이다.
