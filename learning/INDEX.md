# Learning Records Index

가르치는 에이전트가 필요한 기록으로 이동하기 위한 안내이다. 상세 이해 상태는 여기 복제하지 않는다.

| 문서·디렉토리 | 읽는 목적 |
| --- | --- |
| [PROGRESS.md](PROGRESS.md) | 현재 위치와 다음 수업 행동 |
| [RULES.md](RULES.md) | 공통 학습·엔지니어링 실습·증거 기반 평가와 AI 평가자 운영, 기록 갱신·재구성 규칙 |
| [lessons/INDEX.md](lessons/INDEX.md) | 모듈별 수업 재개 요약 선택 |
| [understanding/INDEX.md](understanding/INDEX.md) | 확인하려는 개념에 맞는 최신 이해 기록 선택 |

각 INDEX는 바로 아래 문서·디렉토리만 안내한다. 학습 시작 시 모든 경로를 순회하지 말고 PROGRESS의 현재 수업과 관련 개념 링크를 우선 사용한다.
